# Login Signup Prototype

Minimal React login/signup app with mock backend for interview practice.

## Approach in Interview

1. **Step 1**: Set up project with Vite + React + Tailwind.
2. **Step 2**: Create mock auth API using localStorage.
3. **Step 3**: Build LoginForm component with state and async submit.
4. **Step 4**: Build SignupForm with validation.
5. **Step 5**: Create App component to toggle forms and manage user state.

## Run

```bash
npm install
npm run dev
```

## Notes

- Uses localStorage for mock "database".
- Components are self-contained with their own logic.
- Minimal UI for focus on functionality.
